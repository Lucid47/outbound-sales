# Android 문자·통화 전사 가져오기

## 구현 범위

- Debug APK에서 `READ_SMS` 권한을 요청해 SMS 수신·발신 기록을 가져온다.
- MMS 수신·발신 기록의 제목, 본문, 첨부 개수를 가져온다.
- 한 MMS에 여러 번호가 있어도 선택한 고객리스트에서 한 고객만 명확히 일치할 때만 자동 연결한다.
- 삼성 전화 또는 음성 녹음 앱이 공유한 텍스트, 음성, 음성과 텍스트 묶음을 소희야가자가 받는다.
- 공유 파일명에 포함된 전화번호·고객명·`yyMMdd_HHmmss` 시각과 이미 가져온 통화기록을 조합해 고객을 추천한다.
- 자동 추천 후에도 사용자가 고객을 확인해야 저장할 수 있다.
- 앱으로 복사한 음성과 전사문은 기존 전체·선택 백업과 복원에 포함된다.

## 지원하지 않는 범위

- 채팅+ RCS 대화는 Android 표준 SMS/MMS 저장소에서 제공되지 않아 직접 가져오지 않는다.
- MMS 사진·파일 원본은 현재 히스토리에 복사하지 않고 첨부 개수만 남긴다.
- 삼성 전화 앱의 비공개 데이터베이스나 비공개 전사 파일 경로를 직접 읽지 않는다.
- Release APK에는 Google Play 제한 권한 정책 때문에 `READ_SMS`, `READ_CALL_LOG`를 선언하지 않는다.

## 삼성 전사 가져오기 절차

1. 삼성 전화 앱에서 녹음된 통화를 열고 전사 결과를 확인한다.
2. 공유 메뉴에서 `텍스트 파일` 또는 `음성과 텍스트 파일`을 선택한다.
3. 공유 대상에서 `소희야 가자`를 선택한다.
4. 앱이 추천한 고객과 전사 미리보기를 확인한다.
5. `고객 히스토리에 저장`을 누른다.

텍스트 없이 음성만 공유해도 저장할 수 있다. 이때 최초 전사에는 한국어 Vosk 모델을 한 번 내려받아야 하며 이후에는 기기 내부에서 처리한다.
공유 목록에서 앱을 찾기 어렵다면 `설정 > 통화 녹음·전사 파일 가져오기`에서 텍스트와 음성 파일을 여러 개 직접 선택할 수 있다.

## 실기기 검증

1. 기존 빌드에서 고객, 사진·음성, 히스토리가 보존된 상태로 build 13을 덮어 설치한다.
2. 앱 실행 후 Room 6→7 마이그레이션이 정상이고 기존 음성메모가 재생되는지 확인한다.
3. `설정 > 문자기록 가져오기 > 최근 30일`을 실행한다.
4. SMS와 MMS 본문이 각각 `받은 문자`, `받은 장문·사진문자`로 나타나는지 확인한다.
5. 같은 작업을 다시 실행해 중복 기록이 추가되지 않는지 확인한다.
6. 삼성 전화 앱에서 텍스트만 공유하고 고객 추천·수동 선택·저장을 확인한다.
7. `음성과 텍스트 파일` 공유 후 히스토리에서 녹음 재생과 전사 표시를 확인한다.
8. 텍스트 없이 스테레오 음성을 공유해 오프라인 전사가 끝나는지 확인한다.
9. 전체 백업 후 다른 테스트 데이터베이스에 복원해 통화 녹음과 전사가 유지되는지 확인한다.

## 자동 전사 보강

이전 구현은 Vosk가 완성 구간을 반환할 때 해당 구간을 버리고 마지막 잔여 결과만 저장했다. 긴 음성에서는 마지막 결과가 비어 전사 실패로 보일 수 있었다. 현재 구현은 모든 완성 구간과 마지막 구간을 합치며, 2채널 이상 PCM은 모노로 다운믹스해 처리한다.
