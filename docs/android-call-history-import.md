# Android 통화기록 가져오기

## 목적

갤럭시 기본 전화 앱에서 발생한 통화기록을 선택한 고객리스트의 전화번호와 대조해 고객 히스토리에 추가한다. 앱의 전화 버튼으로 시작한 기록과 구분하기 위해 실제 통화기록은 수신, 발신, 부재중, 거절, 차단, 기타 유형으로 저장한다.

## 배포 구조

- 일반 배포판: `READ_CALL_LOG` 권한을 포함하지 않고 CSV 파일 가져오기만 제공한다.
- 개발용 Debug APK: `src/debug/AndroidManifest.xml`에서만 `READ_CALL_LOG`를 선언한다. 설정 화면에서 최근 30일, 최근 90일, 전체 통화기록을 직접 가져올 수 있다.
- Google Play 공개 배포에서 통화기록 권한은 기본 전화 앱 또는 정책상 허용되는 예외가 아니면 승인되기 어렵다. 따라서 Debug 전용 권한을 일반 매니페스트로 옮기지 않는다.

## CSV 형식

첫 행은 헤더여야 한다. UTF-8, UTF-16, MS949를 자동 판별한다.

필수 열:

- 전화번호: `전화번호`, `번호`, `연락처`, `phone`, `phoneNumber`, `number`
- 통화일시: `통화일시`, `일시`, `날짜`, `date`, `datetime`, `startTime`

선택 열:

- 통화유형: `통화유형`, `유형`, `종류`, `type`, `callType`
- 통화시간: `통화시간`, `통화길이`, `통화초`, `지속시간`, `duration`, `durationSeconds`

지원 시각 예:

- `2026-09-02 14:30:00`
- `2026/09/02 14:30`
- ISO 8601
- Unix epoch 초 또는 밀리초

통화시간 숫자는 초로 해석하며 `mm:ss`, `hh:mm:ss` 형식도 지원한다.

## 매칭 및 중복 규칙

1. `+82 10...`, `010-...`처럼 표기가 달라도 국내 번호로 정규화한다.
2. 현재 선택한 고객리스트 안에서 전화번호가 정확히 한 고객과 일치할 때만 연결한다.
3. 같은 번호를 가진 고객이 둘 이상이면 잘못된 고객에게 연결하지 않도록 미매칭으로 분류한다.
4. 고객, 통화유형, 통화 발생 시각이 모두 같은 기존 기록은 중복으로 제외한다.
5. 통화기록은 기존 `contact_logs`에 저장되므로 고객별 히스토리, 기간 필터, 전체 백업과 복원에 자동 포함된다.

## 실기기 검증

1. 기존 고객 데이터 전체 백업을 만든다.
2. 전화번호가 서로 다른 시험 고객 2명을 별도 고객리스트에 만든다.
3. 각 번호로 수신, 발신, 부재중 통화를 한 번씩 만든다.
4. Debug APK의 `설정 > 통화기록 가져오기 > 최근 30일`을 실행하고 권한을 허용한다.
5. 고객별 기록에서 통화 유형, 실제 통화 시각, 통화시간을 확인한다.
6. 같은 범위를 다시 가져와 신규 0건과 중복 건수를 확인한다.
7. 고객에 없는 번호와 중복 등록된 번호가 다른 고객에게 잘못 연결되지 않는지 확인한다.
8. 백업 후 복원하여 가져온 통화기록이 유지되는지 확인한다.

빌드 성공만으로 제조사 전화 앱의 실제 제공 데이터와 권한 동작까지 검증된 것은 아니다. 최소 한 번은 대상 갤럭시에서 위 절차를 수행한다.
