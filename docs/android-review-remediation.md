# Android 전체 요구사항 후속 구현 상태

기준: 2026-09-06, 기존 build 15 / 40d3ff5에서 시작. 변경 전 origin/feature/android-port가 최신임을 push로 확인했다.
현재 검증 빌드: 0.10.0 (16), Room schema 8.

## 이번 변경

- 전체 복원 시 기존 media 디렉터리를 선삭제하지 않는다. 실패 시 DB 롤백과 함께 기존 파일이 남는다. 이전 미디어의 사후 정리는 아직 보수적으로 하지 않는다.
- ZIP을 로컬에서 완성한 뒤 외부 문서에 쓴다. 외부 문서 제공자는 원자적 교체를 보장하지 않으므로, 업로드 실패 시 사용할 로컬 복구본을 남긴다. 백업 화면에서 최신 로컬 복구본을 선택할 수 있다. 이것은 Drive 측 이전 버전 보존까지 구현했다는 뜻이 아니다.
- 누락된 사진/음성을 성공한 백업으로 취급하지 않는다. 복원 파일 포맷·스키마·미디어 경로를 검증한다.
- 선택 복원은 대시보드 설정을 덮어쓰지 않는다. 같은 이름의 단계만 매핑하며, 매칭되지 않은 단계는 미지정 상태다. 과거 단계 로그 텍스트는 보존한다.
- 주소 수정 시 좌표 캐시를 무효화한다. 현재 위치 실패 후 캐시는 2분 이내·정확도 100m 이내만 허용한다.
- 녹음 세션에 고객 ID를 고정한다. 다른 고객에게 활성/미저장 녹음이 있으면 진입을 막는다. 저장 성공 후 세션 초기화, 중복 저장 방지, 녹음 오류 시 자원 해제를 추가했다.
- 사진 촬영 임시 경로를 rememberSaveable로 유지한다. Activity 재생성에 대비하며, 전체 프로세스 복구는 실제 카메라 테스트가 필요하다.
- 전사 결과에 단어별 시간을 저장한다. 음성 상세의 전체 문장에서 단어 터치 재생·현재 단어 하이라이트·슬라이더·재생 오류 처리를 제공한다. 기존 전사문은 재전사를 실행해야 시간 정보가 생긴다.
- 전사 자체를 WorkManager 작업으로 옮겼다. 기기 내 모델 로딩은 Mutex로 직렬화한다. 작업은 녹음 ID와 경로를 함께 확인해 복원 후 다른 파일에 결과를 기록하지 않도록 한다. 강제 중지·장시간 OS 제한·긴 통화 인식 정확도는 Galaxy 검증이 필요하다.
- 고객카드에 방문·사진·음성 바로가기를 추가했다. 방문 팝업에서 텍스트·사진·음성 선택을 제공한다.
- 텍스트 메모 진입 시 최근 기록과 본문 조회를 추가했다.
- 관리 기간에 이름을 붙이고 현재 조회 결과를 CSV 스냅샷으로 보관한다. 저장 당시 활동을 CSV로 내보내거나 동일 날짜 범위를 다시 조회할 수 있다.
- 고객/리스트 삭제 전에 활동 텍스트를 자동 보관한다. 사진·음성 원본까지 독립된 과거 보고서로 복제하는 구현은 아니다. 관리 기간 보관본은 오래된 백업 복원 시에도 삭제하지 않는다.
- CSV 저장 전 배치 미리보기·전체 선택/해제·행별 선택을 추가했다. 전체 파일을 한꺼번에 UI에 적재하지 않는다.
- 시스템/라이트/다크 모드 선택과 고객카드의 번호·주소·메모·추가 항목 표시 설정을 제공한다. 전체 백업/복원에 표시 설정을 포함한다.

## 문자 읽기 변경과 남은 확인

- READ_SMS 권한을 repository에서도 확인한다. null SMS cursor는 '기록 없음'으로 숨기지 않고 조회 오류로 표시한다.
- 국내/국제 전화번호(+82, 0082, +82(0), tel:, MMS /TYPE=PLMN)를 정규화한다. 고객 번호와 메시지 번호에 같은 규칙을 적용한다.
- 다중 수신자 MMS는 매칭된 고객 각각에게 기록한다. 동일 번호가 고객 여러 명에게 중복 등록되어 모호한 경우는 자동 연결하지 않는다.
- 전체 문자 기록은 200건 배치로 처리한다. 중간 실패 시 앞선 배치는 남고 재실행 시 중복 제외로 이어서 처리한다.
- MMS 접근 오류가 SMS 처리 전체를 막지 않도록 일부 예외를 분리했다. 고객 미매칭은 '선택한 고객리스트' 기준임을 표시한다.
- 실제 Galaxy가 ADB에 연결되지 않아 사용자가 보고한 실패 원인을 확정하지 못했다. READ_SMS 허용 여부, 앱 버전, 선택 리스트, 조회/매칭 결과, SMS인지 RCS인지 확인해야 한다. 메시지 본문·실제 번호를 로그나 Git에 남기지 않는다.
- RCS 비공개 기록 읽기, release 배포 권한 정책 변경은 이번에 구현하지 않았다. 사용자 승인 없이 기본 SMS 앱으로 지정하거나 문자를 발송하지 않았다.

## 검증

- 단위 테스트: 전화번호 정규화 테스트 2개 추가. 기존 문자 결과 문구 테스트 갱신.
- 계측 테스트: 1→8 마이그레이션, 1만 고객 가져오기, 고객/활동/미디어/대시보드, 선택 백업 복원 및 실패 복원 데이터 보존.
- 기존 일부 계측 테스트가 Boolean 반환형으로 컴파일되어 JUnit에서 실행되지 않던 문제를 Unit 반환으로 수정.
- 읽기 전용 API 35 에뮬레이터에서 11개 계측 테스트 통과. 실제 Galaxy 전사·통화·문자·카메라·Drive 검증을 대신하지 않는다.

## 아직 완료하지 않은 항목

전체 요구를 모두 완료했다고 표시하지 않는다. 다음 항목은 후속 구현/검증이 남았다.

1. 방문 지도 스냅샷 저장·썸네일·핀 위치로 지도 열기.
2. 관리 기간 보관 내용을 앱 안에서 표 형태로 탐색하는 화면, 미디어까지 포함한 독립 보관, 보관본 삭제/수명 정책.
3. 개별 사용자 정의 필드별 카드 표시 순서, 임의 개수 주소 UI.
4. 히트맵 글자의 셀 맞춤 자동 크기, 단계 자유 순서·개별 삭제.
5. 누적 터치/방문/완료 고객 집계 필터의 완전한 복원, DB 수준 이력 페이징.
6. 문자 템플릿·개인화·개별 미리보기·일일 집계·상태 복구 UX. 기본 메시지 앱으로 전환하는 합의는 유지한다.
7. Drive 원격 버전 보존·기기간 충돌 해결·iOS와 Android 백업 호환.
8. 녹음 통화 인터럽션 및 프로세스 종료 후 미저장 녹음 복구, 실제 한국어 긴 녹음 품질.
9. 모델/전사 장시간 작업의 OS 중단·절전 재개 실기기 회귀.
10. OCR은 기존 합의 및 이번 우선순위 판단에 따라 후순위 유지.

## 실기기 점검 순서

1. 먼저 현재 데이터 전체 백업을 별도 파일로 보관한다.
2. build 16 설치 후 기존 고객/메모/녹음 유지 확인.
3. 문자 읽기는 전송 없이 최근 30일로 시작해 결과 건수와 미매칭 안내를 확인한다.
4. 고객 A 녹음 후 B 진입 차단, A 저장/재생, 전사 상세/단어 재생 확인.
5. 카메라 전환·회전·Fold 접기/펴기 후 저장 확인.
6. 주소 변경 후 지도 재조회, 위치 권한 거절과 GPS 실패 결과 확인.
7. 합성 테스트 데이터로 선택 복원·손상 복원·로컬 복구본 확인. 실제 고객 자료로 실패 주입하지 않는다.
